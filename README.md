# LamiaCRM

CRM-система. Стек: HTML/CSS/JS (без фреймворков) + Node.js/Express на бэкенде + PostgreSQL.

## Структура проекта

```
LamiaCRM/
├── backend/                  # сервер (Node.js/Express)
│   ├── server.js             # точка входа
│   └── src/
│       ├── config/db.js      # подключение к PostgreSQL (pg Pool)
│       ├── db/
│       │   ├── schema.sql    # SQL-схема таблиц
│       │   ├── init.js       # создаёт таблицы в БД
│       │   └── seed.js       # создаёт аккаунт администратора и пустую главную страницу
│       ├── middleware/auth.js
│       ├── routes/           # auth, profile, admin, home, interactive
│       └── utils/upload.js   # загрузка медиафайлов (multer + sharp)
├── frontend/                 # статический сайт
│   ├── index.html            # главная страница
│   ├── pages/                # login, register, profile, admin, interactive
│   ├── assets/css/style.css
│   ├── assets/js/            # nav.js, api.js, home.js, interactive.js, lightbox.js, login.js, register.js, profile.js, admin.js
│   └── uploads/              # загруженные медиафайлы (главная страница + кнопки Интерактива)
├── .env.example               # шаблон переменных окружения
└── package.json
```

## Требования

- Node.js 18+
- PostgreSQL 14+ (локально установлен и запущен)

## Первый запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте базу данных в PostgreSQL (через `psql` или pgAdmin), например:

   ```sql
   CREATE DATABASE lamiacrm;
   ```

3. Скопируйте `.env.example` в `.env` и укажите свои данные:

   ```bash
   cp .env.example .env
   ```

   В `.env` задайте:
   - `DATABASE_URL` — строка подключения к вашей БД, например
     `postgresql://postgres:ваш_пароль@localhost:5432/lamiacrm`
   - `PORT` — порт сервера (по умолчанию 3000)
   - `SESSION_SECRET` — любая случайная строка

4. Создайте таблицы в базе данных:

   ```bash
   npm run db:init
   ```

5. Заполните начальные данные (аккаунт администратора и пустую главную страницу):

   ```bash
   npm run db:seed
   ```

   Данные администратора по умолчанию:
   - Логин: `Ламия`
   - Почта: `lamia@gmail.com`
   - Пароль: `Password`

   Эти данные можно изменить после входа на странице профиля.

6. Запустите сервер:

   ```bash
   npm run dev
   ```

7. Откройте в браузере [http://localhost:3000](http://localhost:3000).

## Последующие запуски

Достаточно выполнить:

```bash
npm run dev
```

(предполагается, что PostgreSQL уже запущен, а `.env`, таблицы и посевные данные уже настроены на шаге первого запуска).

Для запуска без автоперезагрузки:

```bash
npm start
```

## Реализованный функционал (часть 1 ТЗ)

- Регистрация и вход (логин/почта + пароль), без подтверждения почты; повторная регистрация с уже занятой почтой запрещена.
- Аккаунт администратора с полными правами редактирования сайта.
- Профиль пользователя (кружок с первой буквой логина в правом верхнем углу) — изменение логина, почты и пароля для любого аккаунта, включая администратора; кнопка «Показать пароль» на всех парольных полях.
- Главная страница устроена как блог-лента: заголовок + последовательность блоков (текст и медиа), которые администратор может добавлять, удалять и переставлять местами в любом порядке — медиа не обязательно должно идти в начале. Пока страница не заполнена — отображается пустое состояние. Для гостей (не вошедших в систему) показывается приветственный экран с карточками возможностей и кнопками «Войти» / «Регистрация».
- Изображения при загрузке автоматически сжимаются и конвертируются в WebP (уменьшение до 1920px по большей стороне), кроме GIF — он сохраняется как есть, чтобы не терять анимацию. Видео (mp4, webm, mov) сохраняется как есть, без ограничения по размеру файла (до 10 медиафайлов на страницу).
- Соседние медиаблоки на главной автоматически объединяются в адаптивную сетку — чем больше файлов подряд, тем компактнее плитки, свободное место не остаётся.
- Клик по изображению открывает его в полноэкранном лайтбоксе; видео воспроизводится через нативные элементы управления.
- Сессии пользователей хранятся в PostgreSQL (таблица `session`, создаётся автоматически), поэтому перезапуск сервера не разлогинивает вошедших пользователей.
- Админ-панель: редактор блоков главной страницы (текст/медиа, кнопки перемещения вверх/вниз и удаления) и список пользователей, разделённый на две таблицы — «Администраторы» и «Пользователи» — чтобы админ не терялся среди обычных аккаунтов.
- Раздел «Интерактив»: администратор создаёт кнопки (название + описание + до 10 медиафайлов) в админ-панели, может их редактировать, переставлять и удалять. На самой странице кнопки показаны слева как меню, при клике справа открывается описание и карусель медиа (стрелки/точки-индикаторы, если файлов больше одного); первая кнопка выбирается автоматически, чтобы страница не выглядела пустой.
- Активные области на изображениях («хотспоты»): в админ-панели у каждой картинки есть кнопка «⛶ Разметить» — можно выделить мышью прямоугольную область и привязать к ней текст. На публичной странице при наведении на эту область появляется всплывающая подсказка с этим текстом.
- Навигация (кнопки «Главная», «Интерактив», профиль) видна только авторизованным пользователям; у гостя на любой странице нет навбара — только форма входа/регистрации или приветственный экран.
